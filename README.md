# Home Studio Configuration

Version-controlled technical archive for Salvatore's home office and multimedia production setup.

## Authoritative file

`HOME_STUDIO_CONFIGURATION.md`

This is the single source of truth intended to be uploaded permanently into the ChatGPT project memory.

## Repository structure

- `HOME_STUDIO_CONFIGURATION.md` — complete production baseline
- `docs/apps/` — application-specific views
- `docs/plugins/` — plugin-specific views
- `docs/devices/` — hardware and device settings
- `docs/workflows/` — routing and operational workflows
- `screenshots/source-extracts/` — images extracted from the source DOCX files
- `screenshots/MANIFEST.json` — provenance of extracted images
- `sources/` — original source documents
- `CHANGELOG.md` — configuration history

## Update rule

Any future configuration change must first update the single source of truth and then the relevant split document. Production values must never be silently replaced by proposals or experiments.
