# Home Studio Configuration

Version-controlled technical archive for Salvatore's home office and multimedia production setup.

## Authoritative file

`HOME_STUDIO_CONFIGURATION.md`

This is the single source of truth intended to be uploaded permanently into the ChatGPT project memory.

## Repository structure

- `HOME_STUDIO_CONFIGURATION.md` — complete production baseline
- `docs/apps/` — application-specific views
- `docs/plugins/` — plugin-specific views
- `docs/devices/` — hardware and device settings
- `docs/workflows/` — routing and operational workflows
- `screenshots/source-extracts/` — source-document extracts and direct screenshots; camera/filter-specific folders are distinct from `configurazioni trasversali illuminazione/` for independent ambient lighting
- `screenshots/MANIFEST.json` — provenance of extracted images
- `sources/` — original source documents
- `CHANGELOG.md` — configuration history

## Update rule

Any future configuration change must first update the single source of truth and then the relevant split document. Production values must never be silently replaced by proposals or experiments. The Bookshelf Lamp's optional `Accent Cyan` profile is independent of HOYA/CPL camera settings, and can be enabled or disabled without redefining their validated baselines.
